# E-Commerce Analytics Dashboard

An interactive **E-Commerce Analytics Dashboard** built using Microsoft Excel to analyze sales, orders, customers, product categories, payment methods, regions, and returns.

## Project Overview

This project focuses on converting raw e-commerce transaction data into meaningful business insights using Excel.

## Data Cleaning & Preparation

- Removed duplicate records
- Checked and handled missing values
- Cleaned inconsistent text values
- Used `TRIM()` and `CLEAN()` for text cleaning
- Validated dates, quantities, sales amounts, and other fields
- Standardized categories, regions, and payment methods
- Created additional columns required for analysis

## Excel Functions Used

- `XLOOKUP()` – lookup and retrieve related information
- `IF()` – conditional calculations and classifications
- `IFERROR()` – error handling
- `SUM()` – total calculations
- `AVERAGE()` – average calculations
- `COUNT()` / `COUNTA()` – record and order counts
- `SUMIFS()` – conditional sales calculations
- `TRIM()` / `CLEAN()` – data cleaning

## Data Analysis

Performed analysis on:

- Year-wise sales trends
- Regional sales performance
- Category-wise quantity and sales
- Customer age groups
- Payment methods
- Total orders and quantity
- Returned and non-returned orders
- Average Order Value
- Return Rate

## PivotTables & PivotCharts

Created PivotTables and PivotCharts to summarize and visualize:

- Sales by Year
- Sales by Region
- Sales by Age Group
- Orders by Payment Method
- Quantity by Category
- Returned Orders
